# Честное сравнение: KengaOS vs Windows / Linux / Android / iOS

Дата: 2026-09-10 · KengaOS 0.8. Без маркетинга: ✅ есть · 🟡 частично · ❌ нет.

## Десктоп: KengaOS (ядро ISO) vs Windows 11 vs Ubuntu 24.04

| Категория | KengaOS 0.8 | Windows 11 | Ubuntu 24.04 |
|---|---|---|---|
| Загрузка до рабочего стола | ✅ 1–2 с (ядро+UI в одном образе) | ✅ | ✅ |
| Драйверы устройств | ❌ PS/2, framebuffer, ATA-чтение. Нет: NVMe/AHCI, USB-HID на железе, Wi-Fi, BT, звук, печать | ✅ миллионы устройств | ✅ основное + широкая совместимость |
| Файловая система | 🟡 блочная ATA-запись ✅ (CI-гейт `DISK RW OK`); файловой системы с деревом каталогов нет | ✅ NTFS + журналирование | ✅ ext4 + журналирование |
| Сеть (TCP/IP, Wi-Fi) | ❌ | ✅ | ✅ |
| Графическая среда | 🟡 реальное ядро: Command Center на Kenga; оболочка v0.8 — прототип (веб) | ✅ зрелый DE | ✅ GNOME/KDE |
| Браузер | ❌ своего движка нет (оболочечный рендерит движком хоста) | ✅ Edge | ✅ Firefox/Chromium |
| Приложения | 🟡 шелл с пайпами (`a \| b \| c`), агенты, пророк, магазин (5 манифестов), ring 3 ELF | ✅ миллионы | ✅ миллионы |
| Многозадачность | 🟡 cooperative-агенты; ring 3 — один foreground-процесс | ✅ вытесняющая | ✅ вытесняющая |
| Безопасность | 🟡 capability-модель агентов (новизна); нет пользователей/шифрования/аудита | ✅ | ✅ |
| Установка на железо | ❌ live-демо | ✅ | ✅ |
| Стабильность и зрелость | ❌ прототип, weeks-масштаб | ✅ 40 лет инженерии | ✅ 30+ лет |
| Системный язык | ✅ весь системный слой на Kenga — уникально | ❌ C/C++/C# | ❌ C/Rust |
| ИИ в системе | ✅ пророки: kf_prophet.c в ядре + пророки оболочки, обучающиеся на ходу, локально | 🟡 Copilot (облачной) | ❌ |

**Вердикт (десктоп).** По инфраструктуре (драйверы, ФС, сеть, зрелость) отставание от
Windows/Linux — десятилетия инженерии тысяч людей; «догонять в лоб» бессмысленно и мы
этого не обещаем. Сегодня KengaOS — исследовательская ОС уровня «рабочее демо на голом
железе»: грузится, рисует, работает с агентами, проходит автотесты на каждую сборку.
Наше единственное поле, где мы впереди ОБЕИХ: системный язык для живого ИИ, пророки как
часть ядра (обучаются, локальны, приватны) и агенты первого класса с capability-правами.
Ставка — не «лучше Windows», а «другая ОС»: которая помнит и предсказывает.

## Мобилка: KengaOS Mobile 0.8 (APK) vs Android 13 (MIUI) vs iOS 17

Честно фиксируем статус: KengaOS Mobile сейчас — **оболочка-приложение (WebView)
поверх Android**, а не ОС на железе.

| Категория | KengaOS Mobile 0.8 | Android 13 / MIUI | iOS 17 |
|---|---|---|---|
| Что это | оболочка поверх Android | полноценная ОС | полноценная ОС |
| Звонки | 🟡 набор + передача в системный дозваниватель | ✅ | ✅ |
| SMS | 🟡 чтение реальных SMS, ответ через системный клиент | ✅ | ✅ |
| Контакты | 🟡 чтение | ✅ | ✅ |
| Камера | 🟡 превью + снимок (getUserMedia) | ✅ полная | ✅ полная |
| Браузер | 🟡 страницы kenga:// + внешние через движок хоста | ✅ | ✅ |
| Приложения/магазин | ❌ kpkg v1 = манифесты; нативных приложений нет | ✅ миллионы + Play | ✅ миллионы + App Store |
| Своя ОС на железе телефона | 🟡 ядро работает на aarch64 (QEMU, CI); на телефоне ещё не грузилось | ✅ | ✅ |
| Модем 4G/5G, Wi-Fi, BT | ❌ не начато (самое тяжёлое в отрасли) | ✅ | ✅ |
| ИИ в системе | ✅ пророк оболочки: предсказание действий (Марков), ассистент учится на ходу, всё локально | ❌ | 🟡 Siri (облако) |
| Приватность ИИ | ✅ память только на устройстве | 🟡 | 🟡 |

**Вердикт (мобилка).** Как ОС нас на телефоне пока нет — и это надо признавать прямо.
Сейчас ценность оболочки: (1) доказанный на реальном железе UI-контракт будущей системы,
(2) пророки, которые уже учатся на поведении, (3) готовая сборочная линия APK → когда
ядро встанет на телефон, оболочка переедет с WebView на собственный UI-стек ядра без
смены логики. Путь до своей ОС на POCO M4 Pro: mtkclient → `fastboot boot` (RAM, без
сноса) → bring-up дисплей/тач (недели) → Wi-Fi/BT (месяцы) → модем (самый длинный).
Android/iOS не выигрывают технологией дисплея — они выигрывают экосистемой 15 лет и
миллиардами строк; честный ответ — не копировать их, а занять ниш «ОС, которая учится».

## Приоритеты (из этого сравнения)

1. **Пророки** — главное отличие. Оболочечные уже обучаются (этот релиз). Ядерный
   пророк v2: обучение на системных событиях (IPC/файлы/сеть), память `.km` в ядре.
2. **Приложения**: kpkg v2 = Kenga-исходник → emit-c → ELF в ring 3 — реальный софт.
3. **Десктоп-инфраструктура**: xHCI на живом железе → NVMe/AHCI (запись) → ACPI → Wi-Fi.
4. **Мобилка**: fastboot boot образ → чек-лист железа (`docs/PHONE-TRACK.md`).
