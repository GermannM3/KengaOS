# Аппаратная поддержка — честный статус

Что реально работает при загрузке KengaOS на железе (ISO/USB-флешка),
а чего пока нет. Обновляется по мере драйверов.

## Ноутбук / ПК (x86_64, ISO с GitHub Releases)

| Устройство | Статус | Примечание |
|---|---|---|
| Загрузка BIOS | ✅ | Limine legacy |
| Загрузка UEFI | ✅ | **Secure Boot выключить** (Limine не подписан Microsoft) |
| Экран (framebuffer) | ✅ | Разрешение выбирает Limine/UEFI GOP |
| Встроенная клавиатура | ✅ | PS/2 (i8042) — почти все ноутбуки |
| Тачпад PS/2 | ⚠️ | Классические PS/2-тачпады работают; современные I2C-тачпады (Dell XPS, часть HP/Lenovo) — нет |
| Мышь USB | ❌ | x86-драйвер — только UHCI (QEMU); на железе нужен xHCI/EHCI |
| Таймер/uptime | ✅ | PIT |
| Часы реального времени | ✅ | CMOS RTC |
| Диск (чтение) | ⚠️ | ATA PIO — SATA в режиме IDE/compat; **NVMe — нет** |
| Запись на диск | ❌ | Только чтение; система live, ничего не меняет |
| Wi-Fi / Bluetooth | ❌ | Драйверов нет |
| Звук | ❌ | |
| Батарея / ACPI | ❌ | Выключение — кнопкой питания (жёстко) |

**Вывод:** загрузить и поработать можно — десктоп, клавиатура, терминал,
агенты, магазин. Это live-демо: ничего на диске не меняется и не
сохраняется. Полнценное ежедневное использование — после NVMe/AHCI,
xHCI, Wi-Fi и ACPI (дорожная карта ниже).

## Телефон (aarch64, Oppo/Samsung)

| Этап | Статус |
|---|---|
| Ядро грузится на ARM64 (QEMU virt) | ✅ CI-гейт |
| Загрузка через `fastboot boot` (RAM, без сноса) | 🔜 нужен образ под конкретный SoC |
| Дисплей/тач на конкретном телефоне | ❌ device-specific bring-up |
| Wi-Fi/BT/модем 4G-5G | ❌ самый длинный путь |

Честно: «снести Android и поставить KengaOS» на конкретный Oppo — после
того как ядро поднимет дисплей и тач на его SoC. Порядок работ и
чек-лист пред-сносных тестов — в `docs/PORT-ARM64.md`. Нужна точная
модель телефона.

## Дорожная карта драйверов (десктоп)

1. xHCI/EHCI USB (клавиатура+мышь на реальном железе)
2. AHCI/NVMe (запись, персистентность, установка на диск)
3. ACPI (батарея, кнопки, мягкое выключение)
4. Wi-Fi (начнём с Intel/Qualcomm, чей mainline-референс лучше)
5. Звук (Intel HDA)
