# Разблокировка Oppo A5 2020 (CPH1931RU) — путь к fastboot boot

Цель: получить разблокированный загрузчик, чтобы `fastboot boot` мог
запускать KengaOS из RAM **без сноса Android**. Снос — отдельное решение
ПОСЛЕ зелёного чек-листа (`docs/PORT-ARM64.md`).

Проверено на: CPH1931RU, Android 10, CPH1931EX_11_C.97, bootloader
заблокирован, переключатель «Разблокировка OEM» скрыт (подтверждено adb:
`ro.oem_unlock_supported = 1` — система поддерживает, Oppo скрыл меню).

## Способ 1 — Deep Testing APK (официальный механизм Oppo)

Oppo выпускает приложение «Deep Testing» (глубокое тестирование): оно
подаёт заявку на разблокировку через сервер Oppo. Для CPH1931 APK
распространяется через темы 4pda/XDA (не в магазине).

1. Найти и скачать **DeepTesting APK для Oppo A5 2020 (CPH1931)** — темы:
   4pda «Oppo A5 2020 — прошивки/разблокировка», XDA «[OPPO A5 2020]
   Bootloader unlock». Проверить, что в пакете указана поддержка CPH1931.
2. Установить: `adb install DeepTesting.apk` (отладка уже включена ✓).
3. Открыть приложение, войти в **аккаунт Oppo** (может потребоваться),
   подать заявку на разблокировку. Приложение отправит IMEI/серийник на
   сервер. Возможные сроки одобрения: от мгновенной до ~2 недель
   (телефон должен оставаться включённым с интернетом — политика Oppo).
4. После одобрения приложение предложит перезагрузиться в fastboot —
   согласиться. Проверить с ПК: `fastboot devices` (должен появиться).
5. **ВАЖНО: следующая команда стирает ВСЕ данные телефона.**
   `fastbot flashing unlock` → подтвердить на телефоне (громкость вверх).
6. После перезагрузки: `fastboot flashing unlock_confirm` (если попросит).
   Готово: `fastboot boot kengaos-phone.img` становится доступен.

Если Deep Testing отклоняет заявку на RU-прошивке: запасной путь —
перепрошивка на поддерживающую разблокировку региональную прошивку через
MSM Download Tool (официальный инструмент Oppo, траффик — полный снос,
восстановимая перепрошивка). Ссылки на MSM-пакеты для CPH1931 — в тех же
темах 4pda.

## Способ 2 — EDL (9008) — НЕ рекомендуемый старт

Аварийный режим Qualcomm. Требует подписанный Oppo firehose-загрузчик
(leaked). Юридически и безопасностно серая зона — оставить как крайний
случай восстановления «кирпича», не как путь входа.

## После разблокировки — план загрузки KengaOS

1. `scripts/mkbootimg.py pack --kernel kernel-a64-raw --dtb sm6125.dtb ...`
   → kengaos-phone.img (формат Android boot image — packer готов:
   `scripts/mkbootimg.py`).
2. `fastboot boot kengaos-phone.img` — запуск из RAM **без прошивки**.
   Перезагрузка = снова Android. Ноль риска.
3. Чек-лист bring-up (`docs/PORT-ARM64.md` этап 3): UART/framebuffer/
   тач → Wi-Fi → BT → модем → только потом решение о постоянной установке.

## Что уже готово на стороне ядра

- aarch64-ядро грузится (QEMU, CI-гейт) ✓
- FDT-парсер: memory ✓, uart по имени узла ✓ (compat-скан — доводка)
- Пророк, магазин, ring 3 — в ядре ✓
- mkbootimg.py — packer boot.img ✓ (round-trip тест)

## Чего не хватает для первого `fastboot boot` (по порядку)

1. GICv3 init в ядре (заготовка есть, отладка в QEMU gic-version=3)
2. UART SM6125 (Qualcomm GENI) — ранняя консоль из FDT (адрес из DTB)
3. Framebuffer из ABL (simple-framebuffer / зарезервированная область)
4. Raw arm64 Image-обёртка ядра (сейчас ELF для Limine; телефону нужен
   Image-формат с головой arm64 и x0 = DTB)
